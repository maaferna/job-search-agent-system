Agentic decision support for a job search
with a human in the loop

From public postings to documents a human approved and sent

SCAN ME

1Motivation

A job search is hundreds of small decisions a week: which posting to read, which to discard, what each CV should say. An AI agent reads and writes fast — and it can also invent a fact, forget a rule or attach the wrong file.

This project pairs an AI agent (Claude Code) with written rules, one library of verified facts and blocking checks: the agent does the reading, the human keeps every decision.

3Key components

Claude Code + 25 skillsWritten procedures for every recurring task, and boundaries the agent never crosses.
One library of factsEvery fact lives in one file; per posting the agent proposes fragments and order.
Closed vocabulariesStates, channels and closures validated by a JSON Schema.
Application gate12 blocking checks, from ATS readability to the approval fingerprint.
Rendered-page testA headless browser compares what the board shows with what the data says.
