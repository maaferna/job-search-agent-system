WHO DOES WHATone agent, one owner, written boundaries
AGENT · CLAUDE CODE
Works through 25 written skills
  • Captures and deduplicates postings every day
  • Triages with a written reason; audits each posting before effort is spent
  • Composes the CV in LaTeX from versioned fragments
  • Runs the gate, the ATS audit and the board render test
  • Wrote much of the code, under the owner's direction and review
OWNER · HUMAN
Designs, decides and operates
  • Designed the process, rules, controls and data architecture
  • Writes dated rules; a rule is never edited in place
  • Reads and approves every document's full text
  • Performs every submission
  • Reviews the agent's discards and reopens the wrong ones

DECISIONS THAT DEFINE THE SYSTEM9 ADRs in the repository
Approval before send
The agent prepares; only the human approves the full text and submits.
Gates block
A warning gets read once and ignored. A red check stops the document.
Rules carry dates
When a rule changes, discards made under the old version are surfaced again.
One source of facts
Each fact lives in one file; every CV variant is composed from it.
EVALUATING THE AGENTmeasured against the owner's decisions
TWO METRICS, NEVER MIXED
Fit ≠ call probability
"Would they pick me?" vs. "will anyone read it?". The second is calibrated with a Brier score.
