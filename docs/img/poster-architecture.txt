DECISIONS THAT DEFINE THE SYSTEM
9 ADRs in the repository
Approval before send
The agent prepares; only the human approves the full text and submits.
Gates block
A warning gets read once and ignored. A red check stops the document.
Rules carry dates
When a rule changes, discards made under the old version are surfaced again.
One source of facts
Each fact lives in one file; every CV variant is composed from it.
EVALUATING THE AGENT
measured against the owner's decisions
TWO METRICS, NEVER MIXED
Fit ≠ call probability
"Would they pick me?" vs. "will anyone read it?". The second is calibrated with a Brier score.
