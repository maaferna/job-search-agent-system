1
MOTIVATION
A job search is hundreds of small decisions a week: which posting to read, which to discard, what each CV should say. An AI agent reads and writes fast — and it can also invent a fact, forget a rule or attach the wrong file.
This project pairs an AI agent (Claude Code) with written rules, one library of verified facts and blocking checks: the agent does the reading, the human keeps every decision.

KEY COMPONENTS
Claude Code + 25 skills
Written procedures for every recurring task, and boundaries the agent never crosses.
One library of facts

Closed vocabularies
States, channels and closures validated by a JSON Schema.
Application gate
12 blocking checks, from ATS readability to the approval fingerprint.
Rendered-page test
A headless browser compares what the board shows with what the data says.

DESIGN PRINCIPLES
Approval before send
bound to a fingerprint of the approved text
Gates block, never warn
exceptions are written down, never coded in
Rules carry dates
a changed rule reopens the discards it justified
Every failure becomes a control
each check traces to a real lesson
