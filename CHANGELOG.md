# Changelog

Changes to this public repository. The private system it documents has its own history; the numbers here
are refreshed from it (see [`docs/numbers.yaml`](docs/numbers.yaml)). Versions follow
[semantic versioning](https://semver.org) loosely: a major version changes the structure of the documentation,
a minor one adds a document, a mechanism or an image, a patch fixes text or numbers.

## [1.0.0] — 2026-10-13

First public version.

**Documentation**
- README with a summary for non-technical readers in Spanish, a one-page architecture poster, the board and
  the measured numbers.
- Architecture, the life of a posting, the state machine, audits, quality controls, metrics, the agent's
  operating model, lessons from real failures, a glossary, and nine architecture decision records.

**Examples and code**
- Invented example data with its JSON Schema, seven agent skills and local-model prompts translated from the
  private system, the Claude Code settings and hooks, and a compiling LaTeX library of fragments and
  compositions.
- Reference implementations of six mechanisms, written from scratch, with tests.

**Images**
- Board screenshots and CV previews generated from invented data, and the architecture poster — each one
  regenerated by a tool and covered by a manifest.

**Checks (CI and `make check`)**
- Sanitization gate over text and the visible text of images, links and anchors, published numbers against
  one source, spelling, the example data against its schema, unit tests and the rendered-page test.
