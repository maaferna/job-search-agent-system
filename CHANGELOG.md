# Changelog

Changes to this public repository. The private system it documents has its own history; the numbers here
are refreshed from it (see [`docs/numbers.yaml`](docs/numbers.yaml)). Versions follow
[semantic versioning](https://semver.org) loosely: a major version changes the structure of the documentation,
a minor one adds a document, a mechanism or an image, a patch fixes text or numbers.

## [Unreleased]

**Documentation**
- The README opens with the overview poster and the headline numbers in English; the architecture poster
  moves to [`docs/architecture.md`](docs/architecture.md). *Who did what* and the status line come before
  the first screenshot, and the numbers table lists outcomes before activity.
- Screenshots where the process is explained: a tailored CV and the *today* view in the life of a posting,
  the funnel view in the metrics page.
- One name per thing: *per-application gate*, *response window*; *live discard* added to the glossary.
- The state machine shows withdrawals and replies after an own closure; the agent's boundaries are stated
  as a policy, with a link to the harness rules that would enforce them; the metric on discards is read as
  a lower bound on disagreement, not an accuracy.
- ADRs 0004–0006 name the checks that implement them.
- Tailoring a CV to each posting is stated as a central capability: a new point in the README (both
  languages), the composition step of the life of a posting rewritten as what the agent proposes and what
  the owner decides, and *variant*, *recipe* and *composition report* in the glossary. The overview poster
  shows the same step: one tailored CV per posting, proposed by the agent.

**Examples**
- The `compose-cv` skill, translated from the private original: the eighth example skill.
- An invented composition report for the example Data Engineer application: family, choices with their
  reasons, deviations from the recipe, coverage against the showcase CVs and open gaps.

## [1.0.0] — 2026-10-13

First public version.

**Documentation**
- README with a summary for non-technical readers in Spanish, a one-page architecture poster, the board and
  the measured numbers.
- Architecture, the life of a posting, the state machine, audits, quality controls, metrics, the agent's
  operating model, lessons from real failures, a glossary, and nine architecture decision records.

**Examples and code**
- Invented example data with its JSON Schema, seven agent skills and local-model prompts translated from the
  private system, the Claude Code settings and hooks, and a compiling LaTeX library of fragments and
  compositions.
- Reference implementations of six mechanisms, written from scratch, with tests.

**Images**
- Board screenshots and CV previews generated from invented data, the architecture poster, the overview
  poster and the social card — each one regenerated by a tool and covered by a manifest.

**Maintenance**
- Four skills in `.claude/skills/`: `doc-review`, `refresh-numbers`, `publish-check` and `new-adr`.
- `SECURITY.md` (how to report published data privately) and `CITATION.cff`.

**Checks (CI and `make check`)**
- Sanitization gate over text and the visible text of images, links and anchors, published numbers against
  one source, spelling, the example data against its schema, unit tests and the rendered-page test.
